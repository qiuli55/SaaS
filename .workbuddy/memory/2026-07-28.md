### 01:11 - 修复 AI 无法使用：Vue 模板 JS 表达式里误用 HTML 实体

**问题根因**：用户截图报 `[plugin:vite:vue] Error parsing JavaScript expression: Unterminated string constant. (1:1)`
- 错误位置：`frontend/src/views/DocumentNewView.vue:115:27`
- 真实原因：第115行的 `:placeholder="'...&#10;...'"` 里把 HTML 实体 `&#10;` 误用到了 Vue 模板的 JS 表达式中。在 JS 字符串字面量里 `&#10;` 就是 6 个普通字符 `& # 1 0 ;`，导致解析器误判字符串未闭合
- 修复：改用 ES6 模板字符串 + `\n`（真换行符）+ `${}` 插值
  - 旧：`'详细...&#10;2026年1月15日，' + caseInfo.plaintiff + '与' + caseInfo.defendant + ...`
  - 新：`` `详细...\n2026年1月15日，${caseInfo.plaintiff}与${caseInfo.defendant}...` ``
- Vite HMR 自动重编译，curl `/src/views/DocumentNewView.vue` 已无 error

**关键教训**：Vue 模板 `:attr="..."` 表达式是**纯 JS**，HTML 实体（`&#10;`、`&amp;` 等）**不会解码**。需要换行用 `\n`，需要插值用 `${}`（模板字符串）或字符串拼接
