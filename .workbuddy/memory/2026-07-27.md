## 2026-07-27

### 完成：法律AI助手 V1 MVP 全栈搭建

**技术栈：**
- 后端：Python FastAPI + SQLAlchemy + SQLite + bcrypt + JWT
- 前端：Vue 3 + Vue Router + TailwindCSS + Vite + Axios

**后端（端口 8000）已实现：**
- 用户系统：手机号+密码注册/登录，JWT 认证
- 案件管理：CRUD + 搜索/筛选/分页
- AI 文书生成：调 DeepSeek API，支持 8 种文书类型，法条校验
- Word 导出：python-docx 生成规范格式 .docx
- 文件管理：上传/预览/下载/打包 ZIP
- 历史记录：按时间线查看所有生成记录

**前端（端口 5173）已实现：**
- 登录/注册页
- 工作台首页（最近案件 + 快捷操作）
- 案件列表页（搜索/筛选/分页）
- 案件详情页（案件信息 + 文书/文件 Tab）
- 新建案件页
- 文书生成页（选类型→填信息→AI 生成→复制/下载）
- 文书查看页
- 历史记录页
